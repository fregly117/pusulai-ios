# PusulAI Pro — Native iOS Application

PusulAI Pro'nun saf yerel Swift & SwiftUI iOS projesidir.

## Özellikler
- ⚽ **SofaScore 5-Sekmeli Navigasyon:** Maçlar, Favoriler, PusulAI Copilot, Kuponum, Ayarlar
- 🏟️ **2D Futbol Sahası & Kadro Dizilişleri:** Yeşil çim saha, oyuncu formaları ve taktiksel yerleşim
- 🧠 **PusulAI Copilot:** Dixon-Coles Poisson algoritması ile akıllı kupon üretici
- 📳 **Taptic Engine:** Oran dokunuşlarında ve gol düdüklerinde fiziksel titreşim
- 🔊 **Canlı Gol Sesleri:** Stadyum atmosferi ve gol düdüğü

## Derleme & Kurulum
GitHub Actions `macos-latest` üzerinde Xcode ile otomatik `.ipa` paketler ve **Releases** sekmesinde sunar.
